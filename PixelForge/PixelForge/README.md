# ⚡ PixelForge

**Build. Play. Challenge.**

PixelForge é uma plataforma de minijogos desenvolvida em **Python + Pygame**. O projeto reúne quatro jogos em uma única aplicação, com uma arquitetura modular pensada para crescer com novas funcionalidades.

## 🎮 Jogos

- Pedra, Papel e Tesoura
- Jogo da Velha
- Forca
- Snake

## 🧠 Conceitos praticados

- Programação Orientada a Objetos
- Modularização
- Gerenciamento de estados
- Tratamento de eventos
- Estruturas de dados
- Lógica de jogos
- Interface gráfica com Pygame
- Organização de projetos Python

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/PixelForge.git
cd PixelForge
```

### 2. Crie um ambiente virtual

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

### 4. Execute

```bash
python main.py
```
